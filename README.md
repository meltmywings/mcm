# Main Character Media

Social-first creative and creator agency website built with Vite, TypeScript, modern web platform primitives (`popover`, native `<dialog>`, `:user-invalid`, CSS Anchor Positioning, Scroll-Driven Animations), and Vitest.

## Scripts

```bash
npm run dev      # Start local Vite dev server
npm test         # Run Vitest unit test suite
npm run build    # Type-check and build production bundle to dist/
npm run preview  # Preview production build locally
```
